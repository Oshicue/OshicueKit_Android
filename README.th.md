# Oshicue Kit · Android

[简体中文](README.md) | [繁體中文](README.zh-Hant.md) | [繁體粵語](README.zh-HK.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [ไทย](README.th.md) | [Bahasa Indonesia](README.id.md) | [Bahasa Melayu](README.ms.md)

แอป Android แบบเนทีฟสำหรับจัดตารางการแสดงและการเดินทาง ดูตารางกิจกรรม บันทึกค่าใช้จ่ายซื้อสินค้า และเขียนบันทึกกิจกรรม พัฒนาด้วย **Kotlin, Jetpack Compose และ Material 3** มีห้าแท็บ ได้แก่ กำหนดการ ตารางเวลา สมุดบันทึก บันทึกประจำวัน และการตั้งค่า

เวอร์ชันปัจจุบัน: **0.5.3 (Build 16)** รองรับ **Android 8.0 (API 26) ขึ้นไป** โดยมี ID แอปเป็น `com.oshicue.kit`

## เริ่มต้นใช้งาน

1. ติดตั้ง APK ที่ลงนามแล้ว หรือบิลด์จากซอร์สโค้ดตามคำแนะนำด้านล่าง
2. เมื่อเปิดครั้งแรก แอปจะโหลดข้อมูลตารางเวลาและสมุดบันทึกตัวอย่างที่สมมติขึ้น ส่วนกำหนดการและบันทึกประจำวันจะยังว่างอยู่
3. เปลี่ยนภาษาได้ในการตั้งค่า หรือเปิดหน้าจัดการของแต่ละส่วนเพื่อนำเข้าไฟล์ JSON ของคุณ
4. ส่งออกข้อมูลสำรองของกำหนดการ สมุดบันทึก และบันทึกประจำวันเป็นระยะ และเก็บไฟล์ตารางเวลาต้นฉบับไว้

การนำเข้าตารางเวลาจริงครั้งแรกจะแทนที่ข้อมูลตัวอย่าง หลังจากนั้นแอปจะอัปเดตหรือเพิ่มกิจกรรมตาม ID การนำเข้าสมุดบันทึกจริงครั้งแรกจะแทนที่ตัวอย่างที่ยังไม่เคยแก้ไข ส่วนตัวอย่างที่แก้ไขด้วยตนเองแล้วจะถูกเก็บไว้และรวมกับข้อมูลนำเข้า ชื่อ วันที่ เที่ยวบิน และสถานที่ในตัวอย่างมีไว้สำหรับทดลองใช้เท่านั้น โปรดเปลี่ยนเป็นข้อมูลจริงก่อนใช้งาน

## ฟีเจอร์หลัก

### กำหนดการ

- จัดการ Live เที่ยวบิน โรงแรม ร้านอาหาร และสถานที่อื่น ๆ ในปฏิทิน รองรับกิจกรรมที่กำหนดเวลาและกิจกรรมตลอดวัน เขตเวลา ที่อยู่ และหมายเหตุ กำหนดการส่วนนี้แยกจากรายการที่เลือกไว้ใน “กำหนดการของฉัน” ของตารางเวลา
- บันทึกเวลา เขตเวลา และสนามบินขาออกกับขาเข้าแยกกันได้สำหรับเที่ยวบิน ส่วนโรงแรมใช้เวลาเช็กอินและเช็กเอาต์เป็นจุดในแผนการเดินทาง
- ค้นหาเมืองและสถานที่ และเปิดตำแหน่งหรือเส้นทางในแอปแผนที่ภายนอกได้ ผลการค้นหาจะไม่กำหนดเขตเวลาให้อัตโนมัติ โปรดตรวจสอบด้วยตนเอง
- แสดงช่วงว่างหรือเวลาทับซ้อนระหว่างกิจกรรมที่กำหนดเวลาซึ่งอยู่ติดกัน กิจกรรมตลอดวันจะไม่นำมาเปรียบเทียบช่วงการเดินทาง ขณะนี้ยังไม่มีการประเมินเวลาเดินทางในแอปหรือการตรวจสอบเที่ยวบินแบบเรียลไทม์
- บันทึกสำเนาลงปฏิทินของระบบผ่านหน้าจอแก้ไขปฏิทินของ Android โดยแก้ไขสำเนากับรายการในแอปแยกจากกัน
- มีการค้นหา การใช้ตัวกรองร่วมกัน การเลือกหลายรายการเพื่อลบ การแสดงตัวอย่างการนำเข้า JSON และการสำรองกำหนดการทั้งหมด

### ตารางเวลา

- กรองตามวันที่ กิจกรรม และประเภท LIVE／การขายสินค้า ดูสถานที่ในแนวนอนและเวลาในแนวตั้ง
- แตะครั้งเดียวเพื่อดูรายละเอียดรอบการแสดง แตะสองครั้งหรือกดค้างเพื่อเพิ่มหรือนำออกจาก “กำหนดการของฉัน” และทำเช่นเดียวกันได้ในหน้ารายละเอียด
- รอบที่เวลาทับซ้อนกันจะแสดงเคียงข้างกันพร้อมแจ้งเตือนความขัดแย้ง รองรับการซูม 50%, 70%, 100%, 150%
- เส้นเวลาปัจจุบันรีเฟรชทุก 15 วินาที รอบที่ข้ามเที่ยงคืนจะแยกตามเขตเวลาที่ใช้แสดงผล เมื่อดูหลายกิจกรรม จะใช้เขตเวลาของกิจกรรมแรกในลำดับเอกสารจากกิจกรรมที่เลือก
- รองรับการวางข้อความหรือนำเข้าหลายไฟล์ พร้อมการตรวจสอบและแสดงตัวอย่าง กิจกรรมที่มี ID เดิมจะอัปเดตทั้งกิจกรรมและเก็บกิจกรรมอื่นไว้ หากมี ID กิจกรรมซ้ำในชุดนำเข้าเดียวกัน ระบบจะปฏิเสธ
- ต้องยืนยันก่อนลบกิจกรรม โดยรายการรอบที่เลือกไว้ของกิจกรรมนั้นจะถูกล้าง แต่ข้อมูลสมุดบันทึกและบันทึกประจำวันจะยังอยู่ ขณะนี้ไม่มีเมนูส่งออกตารางเวลา โปรดเก็บไฟล์ต้นฉบับที่นำเข้าไว้

### สมุดบันทึก · Ledger

- ดูจำนวนสินค้าที่ซื้อรายวัน รายเดือน และค่าใช้จ่ายแยกตามสกุลเงินผ่านปฏิทิน พร้อมจัดการวง สมาชิก รูปประจำตัว ประเภทสินค้า และข้อมูลกิจกรรม
- สมาชิกหนึ่งคนสังกัดได้หลายวง โดยแต่ละสังกัดกำหนดสีและราคาเริ่มต้นแยกกันได้ ส่วนการตั้งค่าสมาชิกคนโปรดใช้ร่วมกันทุกสังกัด
- บันทึกวันที่ จำนวน สกุลเงิน ราคาต่อหน่วย และข้อมูลกิจกรรม ณ เวลานั้น รายการใหม่จะอ้างอิงราคาของสมาชิก วง ประเภท และสกุลเงินเดียวกันที่มีวันที่ตรงกับหรือก่อนวันที่เลือกก่อน จากนั้นจึงใช้ราคาที่จำไว้จากการเพิ่มรายการล่าสุด ราคาเริ่มต้นของสมาชิก หรือ 0 ตามลำดับ โดยแก้ไขราคาต่อหน่วยเองได้
- ตารางอันดับรองรับช่วงวัน เดือน ปี และตลอดระยะเวลาที่บันทึก โดยดูได้ตามยอดรวมสมาชิก สมาชิกแยกวง วง จำนวน หรือค่าใช้จ่าย
- รองรับ `CNY`, `JPY`, `HKD`, `TWD`, `USD`, `KRW`, `THB`, `IDR`, `MYR` โดยสรุปแยกแต่ละสกุลเงินและไม่แปลงอัตราแลกเปลี่ยน `JPY`, `KRW` ใช้จำนวนเต็ม ส่วนสกุลอื่นใช้ทศนิยมสองตำแหน่ง ค่า `unitPriceMinor` ใน JSON เป็นจำนวนเต็มในหน่วยย่อยที่สุดของสกุลเงิน
- การนำสมาชิกหรือวงออกจะเก็บข้อมูลและสังกัดที่เกี่ยวข้องไว้เป็นข้อมูลเก่า พร้อมคงข้อมูลการซื้อ ณ เวลานั้นและสถิติไว้ หน้าจัดการรายการรองรับตัวกรอง การลบหลายรายการ การสำรองข้อมูล JSON ทั้งหมด และการนำเข้า

### บันทึกประจำวัน · Diary

- เขียนหัวข้อ เนื้อหา สรุป และแท็ก ใช้สถานะ “ฉบับร่าง” หรือ “เรียบเรียงแล้ว” และเรียกดูตามวันที่ ค้นหา หรือกรองได้
- นำวันที่ ชื่อ เมือง สถานที่จัดงาน และที่อยู่จากกิจกรรมในสมุดบันทึกมาใช้ได้ โดยบันทึกประจำวันจะเก็บสำเนาข้อมูลของตนเอง
- บันทึกอัตโนมัติหลังหยุดแก้ไขประมาณ 0.5 วินาที และบันทึกการเปลี่ยนแปลงที่ค้างอยู่เมื่อกดเสร็จสิ้นหรือปิดตัวแก้ไข หากบันทึกไม่สำเร็จ จะแสดงให้ลองใหม่
- คัดลอกเป็น Markdown／ข้อความธรรมดา ส่งออก `.md`／`.txt` หรือแชร์ผ่านระบบ Android ได้ สถานะ “เรียบเรียงแล้ว” เป็นเพียงสถานะในเครื่อง และการแชร์จะไม่เผยแพร่อัตโนมัติ
- มีการจัดการหลายรายการและการสำรอง JSON ทั้งหมด รายการที่มี ID และเนื้อหาเหมือนกันจะถูกตัดซ้ำ หาก ID เดียวกันมีเนื้อหาขัดแย้งกัน ระบบจะปฏิเสธการนำเข้าทั้งชุด

## แม่แบบ JSON และข้อมูลสำรอง

| เนื้อหา | ไฟล์ที่มีให้ในแอป |
| --- | --- |
| แม่แบบกำหนดการ | [agenda-template.json](app/src/main/assets/templates/agenda-template.json) |
| แม่แบบตารางเวลา | [timetable-template.json](app/src/main/assets/templates/timetable-template.json) |
| ตารางเวลาตัวอย่าง | [demo-timetable.json](app/src/main/assets/templates/demo-timetable.json) |
| แม่แบบสมุดบันทึก | [ledger-template.json](app/src/main/assets/templates/ledger-template.json) |

ไฟล์ JSON ใช้ UTF-8 และนำเข้าผ่านเมนูของแต่ละส่วน โดยแสดงตัวอย่างก่อนยืนยัน โครงสร้าง JSON ของแต่ละส่วนต่างกัน จึงใช้แทนกันไม่ได้แม้จะเป็น `schemaVersion: 1` เหมือนกัน สำหรับบันทึกประจำวัน ให้สร้างหนึ่งรายการแล้วส่งออกข้อมูลสำรองเพื่อดูรูปแบบ ซอร์สโค้ดไม่มีแม่แบบบันทึกประจำวันแยกไว้

## ข้อมูลในเครื่องและการตั้งค่า

ข้อมูลถูกเก็บในไดเรกทอรีส่วนตัวของแอป `filesDir/OshicueKit/` เป็นไฟล์ `agenda.json`, `schedule.json`, `ledger.json`, `diary.json` และ `settings.json` แอปจะจำภาษาและแท็บที่เปิดล่าสุดในเครื่อง รวมถึงรายการที่เลือกไว้ในตารางเวลา

ค่าเริ่มต้นใช้ภาษาตามระบบ หากไม่รองรับจะใช้ภาษาอังกฤษ และเปลี่ยนเองได้ระหว่างเก้าภาษา หน้าตาแอปปรับตามโหมดสว่าง／มืดของระบบ และตอบสนองต่อการตั้งค่าเพิ่มความเปรียบต่างของระบบบน Android 14 ขึ้นไป

บันทึกข้อมูลหลักแบบออฟไลน์ได้โดยไม่ต้องมีบัญชี ขณะนี้ยังไม่มีการซิงก์บนคลาวด์ในแอป การสำรองบนคลาวด์อัตโนมัติ การแจ้งเตือนแบบพุช หรือการนำเข้าจากภาพ การค้นหาสถานที่อาศัยบริการแปลงข้อมูลพิกัดของอุปกรณ์ ส่วนแผนที่ เส้นทาง และปฏิทินภายนอกขึ้นอยู่กับแอปและบริการที่ติดตั้ง ซึ่งอาจต้องใช้อินเทอร์เน็ต โปรดส่งออกข้อมูลสำรองด้วยตนเองก่อนถอนการติดตั้งหรือล้างข้อมูลแอป

## บิลด์จากซอร์สโค้ด

ด้านล่างคือการตั้งค่าของโครงการปัจจุบันและสภาพแวดล้อมที่ใช้สร้างแพ็กเกจครั้งนี้:

| รายการ | เวอร์ชัน |
| --- | --- |
| เวอร์ชันแอป / `versionCode` | `0.5.3` / `16` |
| Android API ขั้นต่ำ / เป้าหมาย / ที่ใช้คอมไพล์ | `26` / `37` / `37` |
| Android Gradle Plugin | `9.4.1` |
| ปลั๊กอิน Kotlin Compose | `2.2.10` |
| Compose BOM | `2026.09.00` |
| เป้าหมายซอร์สโค้ดและไบต์โค้ด Java | `17` |
| Gradle / JBR ที่ใช้ตรวจสอบครั้งนี้ | `9.8.1` / `25.0.3` |

1. เปิดไดเรกทอรีนี้ใน Android Studio แล้วติดตั้ง Android SDK Platform 37 และเครื่องมือบิลด์ที่จำเป็น
2. ใช้ JDK ที่เหมาะสมสำหรับรัน Gradle การตรวจสอบครั้งนี้ใช้ JBR ที่มาพร้อม Android Studio เป้าหมายคอมไพล์ Java `17` และเวอร์ชัน JDK ที่ใช้รัน Gradle เป็นการตั้งค่าคนละส่วนกัน
3. ให้ Android Studio สร้าง `local.properties` หรือกำหนด `sdk.dir` เป็นพาธแบบเต็มของ SDK ในเครื่องด้วยตนเอง อย่าคอมมิตไฟล์นี้
4. เพิ่ม Gradle ที่ติดตั้งแล้วลงใน `PATH` และรันคำสั่งด้านล่างจากไดเรกทอรีนี้ การดาวน์โหลด dependencies ครั้งแรกต้องใช้อินเทอร์เน็ต

ซอร์สโค้ดไม่ได้แนบ Gradle Wrapper มาด้วย คำสั่งต่อไปนี้จึงใช้ `gradle`:

```sh
gradle :app:assembleDebug
gradle :app:testDebugUnitTest :app:lintDebug
```

ตำแหน่ง APK ที่ได้: `app/build/outputs/apk/debug/app-debug.apk` การบิลด์ค่าเริ่มต้นใช้ลายเซ็นสำหรับดีบัก โครงการยังไม่ได้ตั้งค่าลายเซ็นสำหรับเผยแพร่จริง จึงต้องตั้งค่าก่อนเผยแพร่

ซอร์สโค้ดที่ตรงกับแพ็กเกจครั้งนี้ผ่าน **การทดสอบหน่วย 166 รายการ** และ APK ผ่านการตรวจสอบลายเซ็นกับการจัดแนว รีโพซิทอรียังไม่มีชุดทดสอบส่วนติดต่อ Android แบบอัตโนมัติ ควรตรวจสอบแผนที่ ปฏิทินระบบ การเลือกไฟล์ และการแชร์บนอุปกรณ์เป้าหมาย

เมื่ออัปโหลดขึ้น GitHub ให้ยกเว้น `local.properties`, `.gradle/`, `.kotlin/`, `build/`, `app/build/`, ไฟล์ IDE เฉพาะเครื่อง และคีย์ลงนาม

| `app/src/main/assets/localization/` | ข้อความส่วนติดต่อเก้าภาษา |
| `app/src/main/assets/templates/` | แม่แบบ JSON สำหรับกำหนดการ ตารางเวลา และสมุดบันทึก |
| `app/src/main/res/` | ทรัพยากรไอคอน แบบอักษร และธีม |
| `app/src/test/` | การทดสอบหน่วยของส่วนหลัก |
