# Oshicue Kit for Android

[简体中文](README.md) | [繁體中文](README.zh-Hant.md) | [繁體粵語](README.zh-HK.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [ไทย](README.th.md) | [Bahasa Indonesia](README.id.md) | [Bahasa Melayu](README.ms.md)

แอป Android แบบเนทีฟ (Kotlin + Jetpack Compose) สำหรับดูตารางงาน บันทึกค่าใช้จ่ายสินค้า และเขียนบันทึกกิจกรรม มีสี่แท็บตามลำดับคือ ตารางเวลา สมุดบันทึก บันทึกประจำวัน และการตั้งค่า เวอร์ชันปัจจุบันคือ **0.4.0 (versionCode 10)** ตรงกับแอป iOS Oshicue Kit 0.4.0 (build 10) ในด้านฟีเจอร์ และรองรับ Android 8.0 (API 26) ขึ้นไป

## ฟีเจอร์

### ตารางเวลา

- กำหนดการทั้งหมดแบ่งตามสถานที่และ LIVE／สินค้า ใช้ตัวกรองวันที่ เลือกหลายงาน และประเภทงานร่วมกันได้ เลื่อนแนวนอนเพื่อดูสถานที่ และแนวตั้งเพื่อดูเวลา
- แตะกำหนดการหนึ่งครั้งเพื่อดูรายละเอียดทั้งหมด แตะสองครั้งเพื่อติดหรือยกเลิกติดตามกลุ่ม การติดตามใช้ร่วมกันข้ามงานด้วย `artistID` และ "ตารางของฉัน" จะรวมกำหนดการ LIVE และสินค้าของกลุ่มที่ติดตามไว้ โดยแสดงกำหนดการที่ทับซ้อนกันเคียงข้างพร้อมเตือนความขัดแย้ง
- แกนเวลารองรับการซูม 50%, 70%, 100% และ 150% (ค่าเริ่มต้น 100% คือ 4dp／นาที) เมื่อทับซ้อนกันมากจะขยายแนวนอน กำหนดการสั้นจะแสดงชื่อก่อนพร้อมปรับขนาดอักษรอัตโนมัติ และรายละเอียดยังดูได้ครบถ้วน
- เส้นเวลาปัจจุบันใช้เวลาระบบจริง อัปเดตทุก 15 วินาที ปุ่ม "ตอนนี้" จะสลับไปวันนี้เฉพาะเมื่องานที่เลือกมีกำหนดการวันนี้
- เมื่อเลือกหลายงาน ระบบใช้เขตเวลาของงานแรกตามลำดับเอกสาร รายละเอียดแสดงเวลาท้องถิ่นของงานต้นทางได้ และกำหนดการที่ข้ามเที่ยงคืนจะถูกแบ่งตามวันที่ของเขตเวลาที่แสดง
- การนำเข้ารองรับการวาง JSON หรือเลือกไฟล์ UTF-8 JSON หนึ่งไฟล์ขึ้นไป ตรวจสอบ แสดงตัวอย่าง แล้วจึงยืนยัน งานที่มี ID ซ้ำจะถูกแทนที่ทั้งงาน ส่วนงานอื่นคงอยู่ และ ID ซ้ำภายในชุดไฟล์เดียวกันจะถูกปฏิเสธ การลบตารางเวลาต้องยืนยัน และจะล้างการติดตามที่ไม่อยู่ในงานที่เหลืออยู่

### สมุดบันทึก

- ปฏิทินแสดงจำนวนรายวันและรายเดือน พร้อมยอดแยกตามสกุลเงิน แตะการ์ดสมาชิกเพื่อแก้ไขรายการสินค้า หากมีหลายรายการจะให้เลือกก่อน
- จัดการวง สมาชิก รูปโปรไฟล์ สีประจำตัวและราคาเริ่มต้นของแต่ละวง ประเภทการซื้อ และเทมเพลตงาน สมาชิกที่อยู่หลายวงเพิ่มได้ด้วยการเชื่อมกับสมาชิกที่มีอยู่
- บันทึกวันที่ สมาชิกและวง ประเภท จำนวน สกุลเงิน ราคาต่อหน่วย และข้อมูลงานที่เป็นตัวเลือก ซึ่งดึงจากตารางเวลาได้ด้วย
- อันดับดูได้ตามวัน／เดือน／ปี／ตลอดชีวิต รองรับการจัดอันดับด้วยจำนวนหรือยอดใช้จ่าย แบบสมาชิกรวม／สมาชิกแยกตามวง／วง และกรองตามประเภทกับวง อันดับเสมอใช้ `1、1、3` ยอดใช้จ่ายเลือกได้ทีละสกุลเงินและไม่แปลงอัตราแลกเปลี่ยน
- ประวัติจะเก็บสแนปช็อตชื่อ สี งาน และราคาไว้ การลบสมาชิก／วงเป็นการเก็บเข้าคลัง ประวัติและสถิติยังอยู่ และรายการย้อนหลังยังแก้ไขได้
- ตั้งสมาชิกเป็น "สมาชิกโปรด" ได้ โดยจะแสดงบนสุดในหน้าเลือกสมาชิก จำนวนเงินใช้หน่วยย่อยต่ำสุดแบบจำนวนเต็ม รองรับ `CNY`, `JPY`, `HKD`, `TWD`, `USD`, `KRW`, `THB`, `IDR` และ `MYR`
- การจัดการสมุดบันทึกประกอบด้วย จัดการรายการ (กรองตามช่วงวันที่ สมาชิก วง ประเภท สกุลเงิน งาน และข้อความ แล้วลบหลายรายการหรือลบทั้งหมด) ทำความสะอาดแค็ตตาล็อก (เก็บสมาชิก／วงเข้าคลัง) และข้อมูลสำรอง JSON (ส่งออก นำเข้าพร้อมตัวอย่าง ปฏิเสธเมื่อขัดแย้ง)

### บันทึกประจำวัน

- เขียนบันทึกกิจกรรม แก้ไขชื่อเรื่อง เนื้อหา สรุป และแท็ก ตั้งสถานะเป็นฉบับร่างหรือพร้อมเผยแพร่ เรียกดูตามวันที่ของงาน กรองตามสถานะ และค้นหาทั้งข้อความและข้อมูลงาน
- ดึงวันที่ ชื่อ เมือง สถานที่ และที่อยู่จากงานในสมุดบันทึก แล้วแก้ไขต่อได้อย่างอิสระ บันทึกประจำวันเก็บสแนปช็อตของตัวเอง
- หยุดแก้ไขประมาณ 0.5 วินาทีแล้วบันทึกอัตโนมัติ ปิดตัวแก้ไขหรือย้ายแอปไปเบื้องหลังจะบันทึกทันที และบันทึกซ้ำได้เมื่อล้มเหลว
- "เตรียมเผยแพร่" คัดลอก Markdown／ข้อความธรรมดา ส่งออก `.md`／`.txt` หรือใช้แผงแชร์ของระบบได้
- การจัดการบันทึกประจำวันมีตัวกรอง ลบหลายรายการ และสำรอง／นำเข้า JSON

### การตั้งค่าและข้อมูล

- สลับภาษาได้ 9 ภาษา บวกตัวเลือกตามระบบ มีผลทันที และวันที่ เวลา ตัวเลขใช้รูปแบบตามภูมิภาคที่เลือก
- รวมทางเข้านำเข้าตารางเวลา จัดการสมุดบันทึก จัดการบันทึกประจำวัน โหลดตัวอย่าง และข้อมูลเวอร์ชันไว้ที่เดียว
- ทั้งสามโมดูลบันทึกแยกกันในเครื่องที่ `files/OshicueKit/` เป็น `schedule.json`, `ledger.json` และ `diary.json` ด้วยการเขียนแบบอะตอมิก ฟีเจอร์หลักใช้งานออฟไลน์ได้

## การบิลด์และรัน

สิ่งที่ต้องมี:

- JDK 17 ขึ้นไป (แนะนำ JBR ที่มากับ Android Studio หรือ JDK 21+)
- Android SDK Platform 37 และ Build-Tools 36 (Android Studio ติดตั้งให้ได้)
- สร้าง `local.properties` ที่รากรีโพซิทอรีโดยเขียน `sdk.dir=/path/to/Android/sdk` หรือตั้งค่าตัวแปรสภาพแวดล้อม `ANDROID_HOME`
- การบิลด์ครั้งแรกต้องเชื่อมต่อเครือข่ายไปยังที่เก็บ Maven และ Gradle Wrapper จะดาวน์โหลดเวอร์ชันที่กำหนดให้อัตโนมัติ

```sh
./gradlew :app:assembleDebug        # บิลด์ APK สำหรับดีบัก
./gradlew :app:installDebug         # ติดตั้งลงอุปกรณ์หรืออีมูเลเตอร์ที่เชื่อมต่ออยู่
./gradlew :app:testDebugUnitTest    # ยูนิตเทสต์ 93 รายการ (ตรงกับเทสต์ของ iOS แบบ 1:1)
./gradlew :app:lintDebug            # ตรวจสอบแบบสแตติก
./gradlew :app:assembleRelease      # บิลด์ APK สำหรับเผยแพร่
```

### การเซ็นชื่อสำหรับเผยแพร่

รีโพซิทอรีไม่มีวัสดุสำหรับเซ็นชื่อ หากต้องการ APK ที่ติดตั้งและเผยแพร่ได้ ให้สร้าง `keystore.properties` ที่รากรีโพซิทอรี (ไฟล์นี้และ `*.jks` ถูกกันไว้ใน `.gitignore` แล้ว)

```sh
keytool -genkeypair -v -keystore oshicue-kit-release.jks -alias oshicue-kit \
  -keyalg RSA -keysize 2048 -validity 10000
```

```properties
storeFile=oshicue-kit-release.jks
storePassword=รหัสผ่านของคุณ
keyAlias=oshicue-kit
keyPassword=รหัสผ่านของคุณ
```

จากนั้นรัน `./gradlew :app:assembleRelease` ผลลัพธ์จะอยู่ที่ `app/build/outputs/apk/release/app-release.apk` (ถ้าไม่ตั้งค่า `keystore.properties` จะได้ APK ที่ยังไม่เซ็นชื่อ) โปรดสำรอง `oshicue-kit-release.jks` และรหัสผ่านไว้ให้ดี เพราะเวอร์ชันถัดไปต้องใช้ลายเซ็นเดียวกัน

## รูปแบบข้อมูลและความเข้ากันได้

- รูปแบบ JSON ของทั้งสามโมดูลเหมือนกับแอป iOS ทุกประการ (`schemaVersion` เป็น `1`) ไฟล์สำรองที่ส่งออก／นำเข้าจากแอปใช้ร่วมกันระหว่างสองแพลตฟอร์มได้ และโครงสร้างไฟล์ข้อมูลในเครื่องก็เหมือนกัน
- เวลาประทับใช้ ISO 8601 พร้อมมิลลิวินาที (`yyyy-MM-ddTHH:mm:ss.SSSZ`) วันที่ใช้ปฏิทินเกรกอเรียน `yyyy-MM-dd` และจำนวนเงินใช้หน่วยย่อยต่ำสุดแบบจำนวนเต็ม (`unitPriceMinor`)
- การนำเข้าจะตรวจสอบและแสดงตัวอย่างก่อนยืนยันเสมอ รายการที่ ID ซ้ำแต่เนื้อหาต่างกันจะถูกปฏิเสธทั้งชุด เพื่อไม่เขียนทับประวัติ
- `Templates/` และ `docs/` สืบทอดเทมเพลตและเอกสารรูปแบบจากแอป iOS มาใช้ได้โดยตรง

## การแปลภาษา

มีภาษาในตัว 9 ภาษา ได้แก่ จีนตัวย่อ จีนตัวเต็ม (ไต้หวัน) กวางตุ้งตัวเต็ม (ฮ่องกง) English 日本語 한국어 ไทย Bahasa Indonesia และ Bahasa Melayu ไฟล์อยู่ที่ `app/src/main/res/values-*/strings.xml`

`tools/convert_localization.py` ใช้สร้างไฟล์ภาษาในรีโพซิทอรีนี้ใหม่จาก `Localizable.strings` ของแอป iOS (รวมการแปลง `%@` → `%1$s` เป็นอาร์กิวเมนต์แบบระบุตำแหน่ง) หากดูแลเฉพาะฝั่ง Android ให้แก้ `strings.xml` ที่ตรงกันได้เลย

| `tools/` | สคริปต์แปลงทรัพยากรภาษา |

## ความต่างจากแอป iOS

- คอมโพเนนต์ของแพลตฟอร์ม: นำเข้า／ส่งออกไฟล์ใช้ตัวเลือกไฟล์ของระบบ รูปโปรไฟล์ใช้ตัวเลือกรูปภาพของระบบ (ย่อเหลือ 512px, JPEG 0.8, เก็บเป็น Base64 เหมือน iOS) และการแชร์ใช้แผงแชร์ของระบบ
- การเข้าถึง: การกระทำกำหนดเองของ VoiceOver บน iOS เทียบเท่ากับท่าทางแตะ／แตะสองครั้งและเซแมนติกของ Compose
- ส่วนอื่น ๆ ทั้งลำดับการใช้งาน เงื่อนไขขอบ และรูปแบบข้อมูล JSON ตรงกับแอป iOS
