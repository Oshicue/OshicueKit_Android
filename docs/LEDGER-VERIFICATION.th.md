# คู่มือตรวจสอบสมุดบันทึก

[简体中文](LEDGER-VERIFICATION.md) | [繁體中文](LEDGER-VERIFICATION.zh-Hant.md) | [繁體粵語](LEDGER-VERIFICATION.zh-HK.md) | [English](LEDGER-VERIFICATION.en.md) | [日本語](LEDGER-VERIFICATION.ja.md) | [한국어](LEDGER-VERIFICATION.ko.md) | [ไทย](LEDGER-VERIFICATION.th.md) | [Bahasa Indonesia](LEDGER-VERIFICATION.id.md) | [Bahasa Melayu](LEDGER-VERIFICATION.ms.md)

หน้านี้อธิบายขอบเขตการทดสอบที่มีอยู่และขั้นตอนตรวจรับที่ทำซ้ำได้ โดยอ้างอิงซอร์สโค้ดปัจจุบัน การมีไฟล์ทดสอบไม่ได้หมายความว่ารันครั้งนี้ผ่าน รายงานรุ่นเก่า ชุดผลลัพธ์ชั่วคราวและภาพหน้าจอไม่ใช่หลักฐานว่ารุ่นปัจจุบันผ่าน ให้ใช้บันทึกการรันล่าสุดเป็นผลจริง

## ทดสอบแกนหลัก

รันจากโฟลเดอร์รากโครงการ:

```sh
swift test --filter Ledger
```

[LedgerTests.swift](../Tests/LedgerTests.swift) มี 16 การทดสอบ และ [LedgerDeletionTests.swift](../Tests/LedgerDeletionTests.swift) มี 7 ครอบคลุม:

- การเข้ารหัสและถอดรหัสตัวอย่าง/แม่แบบ วันที่ วันอธิกสุรทิน เขตเวลาและขอบเขตวัน/เดือน/ปี/ทั้งหมด
- สรุปประเภทต่อวัน สมาชิกแบบรวมข้ามวงและแยกวง อันดับวง ยอดเงินแยกสกุล อันดับร่วม ลำดับคงที่และสัดส่วนเมื่อยอดใช้จ่ายเป็นศูนย์
- แปลงหน่วยย่อย ปฏิเสธทศนิยมเกิน ราคาศูนย์ จำนวน/ราคาไม่ถูกต้อง และค่าล้นช่วงต่อรายการหรือยอดรวม
- ชื่อ สีและราคาที่เก็บ ณ เวลาซื้อ โดยการแก้ข้อมูลหลักไม่เขียนทับประวัติ
- รวมข้อมูลหลักตาม ID ตัดการซื้อซ้ำ ขัดแย้งเมื่อ ID เดียวแต่เนื้อหาต่าง และความล้มเหลวที่ไม่เปลี่ยนข้อมูลบางส่วน
- ฟิลด์จำเป็น ID ซ้ำ ความสัมพันธ์/ราคาไม่ซ้ำ การอ้างอิง วันที่ สกุลเงิน สี JPEG และขนาดไฟล์
- ไฟล์สำรองเก่าไม่มีฟิลด์เก็บถาวร การเก็บสมาชิกทุกวง การเก็บวง การกรองความสัมพันธ์ใช้งาน การสำรองสถานะเก็บถาวร การแก้ประวัติและคืนข้อมูลหลักโดยไม่เพิ่มยอดซ้ำ

## ทดสอบหน้าจอแบบเนทีฟ

เปิด `OshicueKit.xcodeproj` ใน Xcode เลือก `OshicueKit` scheme กับ iPhone simulator ที่มีอยู่ แล้วรันคลาสทดสอบที่ต้องการ ต้องมี Xcode, iOS SDK และการลงนามตามที่โครงการต้องการ การทดสอบ UI ใช้ไฟล์แยก `ui-test-ledger.json` และตรวจการบันทึกด้วยการปิดโปรเซสแล้วเปิดใหม่

| ไฟล์ทดสอบ | จำนวน | ขอบเขตหลัก |
| --- | --- | --- |
| [LedgerUITests.swift](../UITests/LedgerUITests.swift) | 6 | เพิ่มและบันทึกหลังเปิดใหม่ สมาชิกแบบรวม/แยกวง สกุลเงินใช้จ่าย นำเข้าไม่ถูกต้อง/ถูกต้อง เพิ่มสมาชิกเร็วและราคาเริ่มต้น ชื่อกับทางเข้าปฏิทินทั้งเก้าภาษา |
| [LedgerEditingDeletionUITests.swift](../UITests/LedgerEditingDeletionUITests.swift) | 5 | แก้รายการเดียว เลือกแก้จากหลายรายการ ยืนยันลบการซื้อ ลบสมาชิกทุกวง ลบวง แก้ประวัติและบันทึกหลังเปิดใหม่ |

[LedgerStore.swift](../OshicueKit/Support/LedgerStore.swift) จัดการการโหลดตัวอย่างครั้งแรกและการบันทึก คลาสเก็บข้อมูล UI นี้ไม่อยู่ในแพ็กเกจแกนหลัก หากเปลี่ยนนโยบายต้องตรวจหน้าจอเนทีฟและการเปิดใหม่ร่วมกับทดสอบแกนหลัก

## รายการตรวจรับด้วยตนเอง

1. เปิดสมุดบันทึกใหม่ด้วยข้อมูลทดสอบแยก ต้องเห็นตัวอย่างโดยไม่มีป้าย วันที่สร้างมีจำนวน 10 และทั้งหมด 16 แก้แล้วบันทึกและเปิดใหม่ต้องคงการแก้ สมุดบันทึกเดิมต้องไม่เติมตัวอย่างกลับอัตโนมัติ
2. เพิ่มวงที่สองให้สมาชิกเดิม ตั้งสีและราคาแยก การจัดอันดับรวม/แยกวงต้องเปลี่ยนกลุ่มแต่จำนวนรวมของช่วงคงเดิม ชื่อเดียว ID ต่างต้องแยกสถิติ
3. เพิ่มและแก้การซื้อ ตรวจวันที่ สกุลเงิน ราคาเริ่มต้น จำนวน ข้อมูลงานเสริมและยอดต่อรายการ เมื่อเปลี่ยนความสัมพันธ์/ประเภท/สกุลเงินจะเติมราคาใหม่ ให้ตรวจราคาจริงก่อนบันทึก
4. การ์ดซื้อรายการเดียวต้องเปิดแก้ทันที หลายรายการต้องให้เลือกก่อน บันทึกแก้เฉพาะรายการที่เลือก ยกเลิกลบไม่เปลี่ยนจำนวน ยืนยันแล้วหักจำนวนและเงินและคงผลหลังเปิดใหม่
5. ลบสมาชิกหลายวงต้องซ่อนทุกความสัมพันธ์ ลบวงเดียวต้องคงสมาชิกในวงอื่น ยอดจำนวนและเงินในประวัติคงเดิม ยังแก้ประวัติได้ แต่รายการใหม่เลือกความสัมพันธ์ที่ลบไม่ได้
6. ตรวจ `CNY` ราคา `80.50` จำนวน `2` รวม `161.00` ทศนิยม `JPY`/`KRW` และทศนิยมเกินสองตำแหน่งของสกุลอื่นต้องผิดพลาด จำนวนรวมข้ามสกุลได้ แต่อันดับเงินใช้เฉพาะสกุลที่เลือก
7. ใช้ [ledger-template.json](../Templates/ledger-template.json) ตรวจวาง JSON นำเข้า แสดงตัวอย่างและส่งออก ตัวอย่างที่ยังไม่แก้แทนได้ ตัวอย่างที่แก้แล้วต้องรวม นำเข้าซ้ำไม่เพิ่มยอด ID เดียวแต่การซื้อต่างต้องปิดกั้นทั้งหมด และข้อมูลไม่ถูกต้องต้องไม่เปลี่ยนสมุดบันทึกเดิม
8. คืนข้อมูลหลักที่เก็บถาวรด้วยไฟล์สำรองถูกต้อง ตรวจประวัติแต่ละรายการมีเพียงครั้งเดียว หากคืนรายการที่แก้แล้วด้วยข้อมูลเก่าต้องแจ้งขัดแย้ง
9. สลับภาษาแอปทั้งเก้าภาษา ตรวจสมุดบันทึก ปฏิทิน สถิติ สมาชิก แก้ไข ลบและข้อผิดพลาดนำเข้า รวมถึงการจัดวางชื่อยาว เงินจำนวนมากและหลายสกุล
10. บนอุปกรณ์ทดสอบ ตรวจเลือกรูปจริง ลบรูปสมาชิก เลือกหลายไฟล์และบันทึกด้วยระบบ แล้วทดสอบย้ายไฟล์สำรอง การทดสอบอัตโนมัติไม่ครอบคลุมทุกกล่องโต้ตอบระบบและขั้นตอนใช้รูปจริง

## บันทึกหลักฐาน

ทุกรอบให้บันทึกเวอร์ชันโค้ด วันที่กับเขตเวลา เวอร์ชัน Xcode/ระบบ/อุปกรณ์หรือ simulator คำสั่งหรือคลาสทดสอบ รายการผ่าน/ล้มเหลว/ไม่ได้รัน และบันทึกหรือชุดผลที่เก็บไว้ `screenshots/ledger-*.png` ใช้ทำความเข้าใจหน้าจอได้ แต่ภาพนิ่งไม่ยืนยันการทดสอบปัจจุบันผ่าน การติดตั้งอุปกรณ์จริง ขั้นตอนไฟล์ของระบบและตรวจรับเผยแพร่ต้องบันทึกแยก

## ขั้นตอนตรวจซ้ำด้วยคนเพิ่มเติม

- เปิดหน้าจัดการทั้งสองจากการตั้งค่าและตรวจนำเข้า/ส่งออกเดิมในสำรอง รวมตัวกรอง เลือกบางผลและตรวจจำนวนยืนยัน ยกเลิกก่อนแล้วค่อยยืนยันและเปิดใหม่ ยอดซื้อต้องแยกสกุลเงินและเปลี่ยนกรองต้องล้างการเลือก
- เลือกเก็บถาวรสมาชิกหลายสังกัดกับหนึ่งวง ตรวจขอบเขต สังกัดอื่นและแก้ประวัติ ลบซื้อทั้งหมดแล้วข้อมูลอ้างอิงกับบันทึกยังอยู่ เลือกลบบันทึกตามสถานะ วันที่ ค้นหาและตรวจเนื้อหาที่ไม่เลือกกับส่วนอื่น
- ตั้งสมาชิกโปรดแล้วเปิดผ่านอีกสังกัด ตรวจการตั้งค่าร่วม ส่วนบนหน้าเลือก ราคาตามสังกัดและค่าเริ่มใหม่ ตรวจการยกเลิก เก็บถาวร ส่งออกและนำเข้ากลับ JSON เก่าที่ไม่มี `isFavorite` ต้องไม่โปรดและ `schemaVersion` ยังคง `1`
- เปลี่ยนโหมดสว่าง/มืดของระบบ ตรวจสี่ส่วน รายละเอียด แก้ไข เลือก จัดการและสำรอง รวมถึงข้อความใหญ่ ป้ายยาวเก้าภาษา รูปสมาชิก สี ยอดเงิน ปุ่มที่เลือกและข้อผิดพลาด บันทึกอุปกรณ์กับรุ่นระบบ ไม่ใช้ภาพเก่าแทนผลครั้งนี้
