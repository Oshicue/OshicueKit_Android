# 時間表 JSON 匯入

[简体中文](IMPORT.zh-CN.md) | [繁體中文](IMPORT.zh-Hant.md) | [繁體粵語](IMPORT.zh-HK.md) | [English](IMPORT.en.md) | [日本語](IMPORT.ja.md) | [한국어](IMPORT.ko.md) | [ไทย](IMPORT.th.md) | [Bahasa Indonesia](IMPORT.id.md) | [Bahasa Melayu](IMPORT.ms.md)

使用 UTF-8 JSON。打開時間表嘅匯入入口，可以貼上全文，或者揀一個／多個 `.json`、純文字檔案。驗證成功後會顯示活動同場次數量，撳確認先會套用。改過預覽入面嘅文字，要重新驗證。

## 更新同收藏

第一次啟動會產生同儲存兩份虛構日程，以啟動時東京當地嘅整點為基準，亦包括翌日排期；預設收藏頭兩個團體。標題唔會顯示示例標記，之後啟動會讀取已儲存資料。第一次正式匯入會取代仍然處於示例狀態嘅日程，並清除示例收藏。之後匯入會保留其他活動，相同活動 `id` 就會取代嗰個活動嘅完整內容，更新時要提供完整活動，唔好只交部分場次。

團體 `id` 係跨活動共用嘅收藏身份。改名時保留 ID，收藏就可以延續；連撳兩下 LIVE 或物販方塊會切換嗰個團體嘅收藏。我的日程會按已揀活動同日期，合併顯示收藏團體嘅 LIVE、物販。時間重疊係有效排期，會並排顯示同提示衝突；提示只比較時間，唔會評估交通或趕場是否可行。

## 欄位

| 位置 | 欄位 | 規則 |
| --- | --- | --- |
| 最上層 | `schemaVersion` | 必填整數，固定係 `1`。 |
| 最上層 | `events` | 必填活動陣列。匯入入口要求最少一個活動，整批最少一個場次。 |
| 活動 | `id`, `name`, `city` | 必填非空字串。活動 ID 喺整批入面要唯一。 |
| 活動 | `timeZone` | 必填有效 IANA 時區，例如 `Asia/Tokyo`。 |
| 活動 | `venues`, `artists`, `sessions` | 必填陣列；容許個別活動冇場次。 |
| 場館 | `id`, `name`, `color` | 非空 ID、名稱；顏色一定要係 `#RRGGBB`，例如 `#78C9EB`。 |
| 團體 | `id`, `name` | 必填非空字串。團體 ID 應該跨活動保持穩定。 |
| 場次 | `id`, `artistID`, `venueID` | 非空場次 ID；引用本活動聲明嘅團體同場館。 |
| 場次 | `kind` | 只可以係 `live` 或 `goods`。 |
| 場次 | `startsAt`, `endsAt` | 完整 ISO 8601 日期時間，包括秒同 `Z` 或明確偏移；結束一定要遲過開始。 |
| 場次 | `area`, `notes` | 可選字串，可以省略或用 `null`。 |

場館、團體、場次 ID 各自在所屬活動入面要唯一。必填字串唔可以只得空白。JSON 唔支援註解或尾隨逗號。可以輸入未知欄位，但 App 唔會顯示，重新編碼亦唔會保留。

## 驗證同批次匯入

錯誤會顯示欄位路徑，例如 `$.events[0].sessions[2].endsAt`。版本、類型、日期、時區、顏色、重複 ID、無效引用或時長出錯，都會中止整份內容嘅驗證。多個檔案會先合併再一齊驗證，跨檔案重複活動 ID 亦會失敗；任何一個檔案失敗，都唔會匯入部分內容。匯入入口唔可以套用空活動陣列或完全冇場次嘅整批內容；底層容許 `events: []`，用嚟儲存刪空後嘅內部狀態。

## 時區同跨午夜

接受 `2026-10-14T12:00:00+09:00`、`2026-10-14T03:00:00Z` 同小數秒。`12:00`、冇秒數或時區嘅值都無效。偏移決定絕對時刻，活動 `timeZone` 決定當地日期；要按場次實際時區填寫。夏令時間重複小時嘅 `2026-11-01T01:30:00-04:00` 同 `2026-11-01T01:30:00-05:00` 係兩個時刻。

跨午夜要寫翌日結束日期：`2026-10-14T23:40:00+09:00` → `2026-10-15T00:20:00+09:00`。場次會喺涵蓋嘅兩個日期出現，圖塊只顯示當日部分；啱啱喺 `00:00:00` 結束唔會加多個空白日期。冇人為嘅最長時長限制。

同時揀唔同時區活動時，目前介面統一用已揀活動中排第一嘅活動時區，顯示日期、時間同詳情，並喺篩選列標明時區。要睇某個活動自己嘅當地時間，請單獨揀嗰個活動。現在時間線用真實系統時間，固定示例日期未必係今日。

## 編輯範本

複製文末連結入面嘅時間表範本，保留 `schemaVersion` 同 `events`，填好穩定 ID，再複製場次修改引用、類型同時間。範本嘅活動、團體同排期全部都係虛構；範本唔會自動匯入。
