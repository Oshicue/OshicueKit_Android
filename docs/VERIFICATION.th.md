# แนวทางตรวจสอบตารางเวลา

[简体中文](VERIFICATION.md) | [繁體中文](VERIFICATION.zh-Hant.md) | [繁體粵語](VERIFICATION.zh-HK.md) | [English](VERIFICATION.en.md) | [日本語](VERIFICATION.ja.md) | [한국어](VERIFICATION.ko.md) | [ไทย](VERIFICATION.th.md) | [Bahasa Indonesia](VERIFICATION.id.md) | [Bahasa Melayu](VERIFICATION.ms.md)

หน้านี้อธิบายขอบเขตการตรวจสอบในซอร์สปัจจุบันและวิธีตรวจซ้ำ การมีไฟล์ทดสอบไม่ได้หมายความว่าได้รันในการปรับปรุงครั้งนี้ ภาพหน้าจอเก่าใช้เป็นตัวอย่างหน้าจอ ไม่ใช่หลักฐานว่าบิลด์ปัจจุบันผ่าน

## การตรวจที่ทำซ้ำได้

รันจากไดเรกทอรีหลักของโครงการ:

```sh
swift test
python3 scripts/verify-localizations.py
```

`swift test` รันทดสอบแกนกลาง Foundation ไม่ได้รันทดสอบหน้าจอ iOS การตรวจภาษาเช็กชุดคีย์ ข้อความที่ไม่ว่าง ตัวแทนค่าในรูปแบบ และไวยากรณ์ `.strings` ของทั้งเก้าภาษา

| ไฟล์ | ขอบเขต |
| --- | --- |
| [ScheduleImporterTests.swift](../Tests/ScheduleImporterTests.swift) | ข้อผิดพลาดรูปแบบและฟิลด์ การอ้างอิงและ ID ซ้ำ ค่าเยื้องเวลา เศษส่วนวินาที เที่ยงคืน เวลาออมแสง การอัปเดตอีเวนต์ทั้งรายการ แม่แบบและการสร้างตัวอย่างเริ่มต้น |
| [TimelineLayoutTests.swift](../Tests/TimelineLayoutTests.swift) | ขอบเวลาที่ต่อกัน การแบ่งช่องเมื่อซ้อน จำนวนช่องพร้อมกันขั้นต่ำ ลำดับที่คงที่ ความกว้างคอลัมน์หนาแน่น และการไม่ทับกันในแนวนอน |
| [ScheduleDeletionTests.swift](../Tests/ScheduleDeletionTests.swift) | การลบอีเวนต์ รายการโปรดร่วม ชื่อเดียวแต่ ID ต่างกัน ID ที่ไม่รู้จัก การเข้ารหัสและโหลดเอกสารว่างใหม่ |

## ตรวจหน้าจอเนทีฟซ้ำ

เปิดโครงการใน Xcode และรัน UI tests บนตัวจำลอง iOS กรณีหลักอยู่ใน [OshicueKitUITests.swift](../UITests/OshicueKitUITests.swift), [TimelineReadabilityUITests.swift](../UITests/TimelineReadabilityUITests.swift) และ [ScheduleDeletionUITests.swift](../UITests/ScheduleDeletionUITests.swift)

ตรวจการแตะครั้งเดียวดูรายละเอียด แตะสองครั้งเพิ่มรายการโปรด รวมประเภทในตารางของฉัน การไม่สามารถยืนยันข้อมูลนำเข้าที่ผิด การแทนที่ตัวอย่างด้วยข้อมูลที่ถูกต้อง การเลือกและสลับเก้าภาษา การอ่านช่วงสั้นและขายสินค้าพร้อมกัน การยืนยันลบ การปรับรายการที่เลือก และการเปิดใหม่เมื่อมีตารางว่าง DEBUG UI tests ใช้ไฟล์ตารางแยกด้วย `OSHICUE_UI_TESTS=1`; `OSHICUE_PRESERVE_UI_DATA=1` เก็บข้อมูลทดสอบไว้เมื่อเปิดใหม่

## การตรวจด้วยตนเองเพิ่มเติม

นำเข้าหลายไฟล์และยืนยันว่าไฟล์ผิดหรือ ID อีเวนต์ซ้ำข้ามไฟล์ไม่ทำให้ใช้ข้อมูลเพียงบางส่วน เลือกอีเวนต์ต่างเขตเวลาแยกกันและพร้อมกัน แล้วตรวจเขตเวลาในแถบตัวกรอง ตรวจช่วงที่ข้ามเที่ยงคืนและสิ้นสุดตรงเที่ยงคืน จากนั้นเพิ่มขนาดข้อความระบบแล้วตรวจรายละเอียดซ้ำ หลังลบให้ตรวจว่าสแนปช็อตบัญชีและบันทึกยังอยู่ และตรวจตารางกับรายการโปรดหลังเปิดใหม่

การตรวจในตัวจำลองไม่แทนการตรวจอุปกรณ์จริง ระบบหลายเวอร์ชัน ข้อความขนาดใหญ่ หรือหน้าต่างเลือกไฟล์ บันทึกผลจริงของการทดสอบ UI การติดตั้งอุปกรณ์จริงและการเผยแพร่ครั้งนี้แยกกัน [โฟลเดอร์ภาพหน้าจอ](../screenshots/) ที่มีอยู่เก็บตัวอย่างหน้าจอในอดีต

## ทดสอบซ้ำการจัดการ สมาชิกโปรดและรูปลักษณ์ 0.4.0

ต่อไปนี้คือข้อกำหนดทดสอบและขอบเขตตรวจซ้ำที่เพิ่มสำหรับ 0.4.0 / build 10 ไม่ได้ยืนยันว่าได้รันและผ่านทุก UI test ครั้งนี้ ให้บันทึกผ่าน ล้มเหลวหรือยังไม่รันตามผลจริง การตรวจชุดสีก็ไม่แทนการตรวจแต่ละหน้าด้วยตา

| ไฟล์ทดสอบ | จำนวน | ขอบเขตที่เพิ่ม |
| --- | --- | --- |
| [DataManagementUITests.swift](../UITests/DataManagementUITests.swift) | 6 | กรองซื้อและเลือกหลายรายการ ยกเลิก/ยืนยัน เปลี่ยนกรองล้างเลือก ลบทุกสกุลเงิน ลบบันทึกหลายฉบับและแบบฟอร์มสำรองในหน้าจัดการของการตั้งค่า เลือกข้อมูลอ้างอิงหลายรายการ ยกเลิก/ยืนยันการเก็บถาวรและเก็บประวัติซื้อไว้ |
| [DataManagementFailureUITests.swift](../UITests/DataManagementFailureUITests.swift) | 2 | ใช้ `OSHICUE_FAIL_BATCH_DELETE=1` จำลองความล้มเหลวในการบันทึกจริงกับข้อมูลทดสอบ Debug แยกต่างหาก ตรวจว่ารายการเดิม เนื้อหาบันทึกและการเลือกปัจจุบันยังอยู่ ข้อมูลไม่เปลี่ยนหลังเปิดใหม่ และเลือกอีกครั้งเพื่อลองลบหลังปิดการจำลองความล้มเหลว |
| [AppearanceUITests.swift](../UITests/AppearanceUITests.swift) | 5 | ชุดสี UIKit แบบไดนามิกจริง ความต่างสีข้อความและตัวควบคุมที่เลือกในสองโหมด พื้นหลังสถานที่ เพิ่มความต่างสีและอ่านสีสมาชิกได้ โดยไม่ได้กดใช้งานหน้าแอป |
| [AppearanceScreenUITests.swift](../UITests/AppearanceScreenUITests.swift) | 1 | ใช้งานจริงทั้งสี่ส่วน สมาชิกโปรดและการเลือก การแก้ไข จัดการและสำรองในโหมดสว่างหรือมืดของระบบ แอปไม่บังคับธีม และแนบภาพหน้าจอจริง 13 ภาพหลังตรวจหน้าจอ |

```sh
xcodebuild test -project OshicueKit.xcodeproj -scheme OshicueKit -destination 'platform=iOS Simulator,id=<SIMULATOR_ID>' -only-testing:OshicueKitUITests/AppearanceUITests -only-testing:OshicueKitUITests/DataManagementFailureUITests -only-testing:OshicueKitUITests/AppearanceScreenUITests
```

## ขั้นตอนตรวจซ้ำด้วยคนเพิ่มเติม

- เปิดหน้าจัดการทั้งสองจากการตั้งค่าและตรวจนำเข้า/ส่งออกเดิมในสำรอง รวมตัวกรอง เลือกบางผลและตรวจจำนวนยืนยัน ยกเลิกก่อนแล้วค่อยยืนยันและเปิดใหม่ ยอดซื้อต้องแยกสกุลเงินและเปลี่ยนกรองต้องล้างการเลือก
- เลือกเก็บถาวรสมาชิกหลายสังกัดกับหนึ่งวง ตรวจขอบเขต สังกัดอื่นและแก้ประวัติ ลบซื้อทั้งหมดแล้วข้อมูลอ้างอิงกับบันทึกยังอยู่ เลือกลบบันทึกตามสถานะ วันที่ ค้นหาและตรวจเนื้อหาที่ไม่เลือกกับส่วนอื่น
- ตั้งสมาชิกโปรดแล้วเปิดผ่านอีกสังกัด ตรวจการตั้งค่าร่วม ส่วนบนหน้าเลือก ราคาตามสังกัดและค่าเริ่มใหม่ ตรวจการยกเลิก เก็บถาวร ส่งออกและนำเข้ากลับ JSON เก่าที่ไม่มี `isFavorite` ต้องไม่โปรดและ `schemaVersion` ยังคง `1`
- เปลี่ยนโหมดสว่าง/มืดของระบบ ตรวจสี่ส่วน รายละเอียด แก้ไข เลือก จัดการและสำรอง รวมถึงข้อความใหญ่ ป้ายยาวเก้าภาษา รูปสมาชิก สี ยอดเงิน ปุ่มที่เลือกและข้อผิดพลาด บันทึกอุปกรณ์กับรุ่นระบบ ไม่ใช้ภาพเก่าแทนผลครั้งนี้
