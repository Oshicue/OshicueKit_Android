# 时间表 JSON 导入

[简体中文](IMPORT.zh-CN.md) | [繁體中文](IMPORT.zh-Hant.md) | [繁體粵語](IMPORT.zh-HK.md) | [English](IMPORT.en.md) | [日本語](IMPORT.ja.md) | [한국어](IMPORT.ko.md) | [ไทย](IMPORT.th.md) | [Bahasa Indonesia](IMPORT.id.md) | [Bahasa Melayu](IMPORT.ms.md)

使用 UTF-8 JSON。打开时间表的导入入口，可粘贴全文或选择一个／多个 `.json`、纯文本文件。校验成功后显示活动及场次数量，点击确认才应用。编辑预览中的文本后需要重新校验。

## 更新与收藏

首次启动会生成并保存两份虚构日程，以启动时的东京当地整点为基准，并包含次日排期；初始收藏前两个团体。标题不显示示例标识，之后启动读取保存资料。首次正式导入会替换仍处于示例状态的日程并清空示例收藏。此后的导入保留其他活动，同一活动 `id` 则替换其完整内容，更新时应提供完整活动而非局部场次。

团体 `id` 是跨活动共用的收藏身份。保留 ID 可在改名后延续收藏；双击 LIVE 或物贩方块会切换该团体收藏。我的日程按所选活动和日期合并显示收藏团体的 LIVE、物贩。时间重叠合法，会并排显示并提示冲突；提示只比较时间，不评估交通或赶场可行性。

## 字段

| 位置 | 字段 | 规则 |
| --- | --- | --- |
| 顶层 | `schemaVersion` | 必填整数，固定为 `1`。 |
| 顶层 | `events` | 必填活动数组。导入入口要求至少一个活动，整批至少一个场次。 |
| 活动 | `id`, `name`, `city` | 必填非空字符串。活动 ID 在整批内唯一。 |
| 活动 | `timeZone` | 必填有效 IANA 时区，如 `Asia/Tokyo`。 |
| 活动 | `venues`, `artists`, `sessions` | 必填数组；允许某个活动没有场次。 |
| 场馆 | `id`, `name`, `color` | 非空 ID、名称；颜色必须为 `#RRGGBB`，如 `#78C9EB`。 |
| 团体 | `id`, `name` | 必填非空字符串。团体 ID 应跨活动稳定。 |
| 场次 | `id`, `artistID`, `venueID` | 非空场次 ID；引用本活动声明的团体和场馆。 |
| 场次 | `kind` | 只能是 `live` 或 `goods`。 |
| 场次 | `startsAt`, `endsAt` | 完整 ISO 8601 日期时间，含秒及 `Z` 或明确偏移；结束必须晚于开始。 |
| 场次 | `area`, `notes` | 可选字符串，可省略或为 `null`。 |

场馆、团体、场次 ID 分别在所属活动内唯一。必填字符串不能只含空白。JSON 不支持注释或尾随逗号。未知字段可输入，但 App 不展示，重新编码时也不会保留。

## 校验与批量导入

错误会显示字段路径，如 `$.events[0].sessions[2].endsAt`。版本、类型、日期、时区、颜色、重复 ID、无效引用或时长错误均中止整份内容的校验。多文件先合并后统一校验，跨文件重复活动 ID 也会失败；任何文件失败都不会部分导入。空活动数组或整批没有场次不能在导入入口应用；底层允许 `events: []` 保存删空后的内部状态。

## 时区与跨午夜

接受 `2026-10-14T12:00:00+09:00`、`2026-10-14T03:00:00Z` 和小数秒。`12:00`、缺少秒数或时区的值均无效。偏移决定绝对时刻，活动 `timeZone` 决定当地日期；应按场次实际时区填写。夏令时重复小时的 `2026-11-01T01:30:00-04:00` 与 `2026-11-01T01:30:00-05:00` 是两个时刻。

跨午夜需写次日结束日期：`2026-10-14T23:40:00+09:00` → `2026-10-15T00:20:00+09:00`。场次出现在覆盖的两个日期，图块裁切到当天；恰好在 `00:00:00` 结束不会增加空白日期。没有人为的最长时长限制。

同时选择不同时区活动时，当前界面统一采用所选活动中排在首位的活动时区来显示日期、时间和详情，并在筛选栏标明时区。要查看某活动自己的当地时间，请单独选择该活动。现在时间线使用真实系统时间，固定示例日期不一定是今天。

## 编辑模板

复制文末链接中的时间表模板，保留 `schemaVersion` 和 `events`，填写稳定 ID，再复制场次修改引用、类型和时间。模板中的活动、团体及排期均为虚构内容；模板不会自动导入。
