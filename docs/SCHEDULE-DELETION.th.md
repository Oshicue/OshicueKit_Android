# ลบตารางเวลา

## วิธีใช้

เปิดหน้าเลือกอีเวนต์จากตารางเวลา แต่ละตารางมีปุ่มลบสีแดงพร้อมไอคอนถังขยะ เมื่อแตะจะมีข้อความยืนยันพร้อมชื่อเป้าหมาย ยกเลิกเพื่อเก็บข้อมูล หรือยืนยันเพื่อลบอีเวนต์และทุกช่วง LIVE กับขายสินค้า การเลือกและการลบอีเวนต์เป็นคนละคำสั่ง

การลบจะเขียนไฟล์ในเครื่องให้สำเร็จก่อนอัปเดตหน้าจอ หากบันทึกไม่สำเร็จจะแสดงข้อผิดพลาดและเก็บตารางเดิมไว้ให้ลองใหม่ได้ ลบอีเวนต์ที่ไม่ได้เลือกจะไม่เปลี่ยนตัวเลือกอื่น หากลบอีเวนต์เดียวที่เลือกอยู่ จะเลือกอีเวนต์ที่เหลือโดยอัตโนมัติและปรับวันที่ด้วย

## รายการโปรดและข้อมูลแยกกัน

เก็บเฉพาะรายการโปรดของวงที่ยังประกาศในอาร์เรย์ `artists` ของอีเวนต์อื่น ไม่ตัดสินจากชื่อที่แสดงหรือการมีช่วงเหลืออยู่ วงชื่อเดียวแต่ ID ต่างกันไม่ใช้รายการโปรดร่วมกัน

บัญชีและบันทึกเก็บข้อมูลและสแนปช็อตอีเวนต์แยกกัน การลบตารางไม่ลบรายการซื้อ สถิติ หรือร่างบันทึก เมื่อลบอีเวนต์ทั้งหมดจะบันทึกตารางว่างและยังว่างหลังเปิดใหม่ สามารถนำเข้าใหม่หรือเลือกโหลดตัวอย่างจากการตั้งค่า การโหลดตัวอย่างจะรวมตาม ID อีเวนต์ตัวอย่างและเก็บอีเวนต์ที่มี ID อื่นไว้

## ตรวจซ้ำ

1. นำเข้าสองอีเวนต์ที่มี ID วงร่วมหนึ่งวงและวงเฉพาะของแต่ละอีเวนต์ เพิ่มวงร่วมและวงเฉพาะของอีเวนต์ที่จะลบเป็นรายการโปรด
2. ตรวจชื่อในข้อความยืนยันลบ แล้วยกเลิกก่อน ตรวจว่าอีเวนต์ ช่วงกิจกรรม และตัวเลือกยังอยู่
3. ยืนยันลบ ตรวจว่าช่วงของเป้าหมายหายไป รายการโปรดร่วมยังอยู่ และรายการโปรดที่ประกาศเฉพาะในอีเวนต์ที่ลบถูกลบ ตรวจตัวเลือกและวันที่ที่เหลือ
4. ลบอีเวนต์ที่ไม่ได้เลือก ตรวจว่าตัวเลือกอื่นยังอยู่ และข้อมูลบัญชีกับบันทึกไม่ได้รับผลกระทบ
5. ลบทั้งหมดแล้วเปิดใหม่ ตรวจว่าไม่คืนตัวอย่าง จากนั้นนำเข้าและเพิ่มรายการโปรดอีกครั้งเพื่อยืนยันว่าใช้งานได้ตามปกติ

การตรวจแกนกลางอยู่ใน [ScheduleDeletionTests.swift](../Tests/ScheduleDeletionTests.swift) และการตรวจการทำงานเนทีฟอยู่ใน [ScheduleDeletionUITests.swift](../UITests/ScheduleDeletionUITests.swift) ครั้งนี้ไม่ได้รัน UI tests ใหม่
